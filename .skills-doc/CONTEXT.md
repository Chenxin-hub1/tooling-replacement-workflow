# 模具更换工作流术语

本词表记录本项目采用的业务工作定义。BPW 的用途按用户提出的解释统一，英文全称仍待业务确认。

## Language

**BPW（变更审批流程）**：
围绕换模具、工程变更或生产转移而办理的可追踪审批流程，以审批单编号、计划批准日期和办理进度描述。Business Process Workflow 仅为候选英文全称，尚未确认。
_Avoid_：把 Business Process Workflow 写成已确认的官方全称；把 BPW 与 PPAP 混为同一审批。

**Core BPW（内部变更审批）**：
内部审批阶段的 BPW，由 PM 协调相关内部职能办理，记录编号和发起、进行、完成状态。
_Avoid_：仅有 BPW 编号就视为已完成；把内部完成等同于客户批准。

**OEM BPW（客户相关变更审批）**：
客户审批阶段的 BPW，表示面向特定客户的变更审批或在内部流程中登记的客户批准记录。此名称不表示客户必然直接操作内部系统。
_Avoid_：将 OEM BPW 一概理解为客户登录并亲自办理的流程。

**BPW number（BPW 审批单编号）**：
用于定位和追踪某次 BPW 流程的标识。编号存在本身不证明审批已完成。

**BPW completion（BPW 流程完成）**：
对应范围内的变更审批已办理完成。内部审批与客户相关审批分别判断，不能互相替代。
