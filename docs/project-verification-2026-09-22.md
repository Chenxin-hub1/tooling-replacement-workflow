## 已修复

| 问题 | 修复与证据 |
| --- | --- |
| 无账号模式下，任意网站可跨域访问本机 API | 默认关闭跨域，API 校验 Origin，同源及明确允许来源可用；新增外站拒绝和允许来源测试。不是身份认证，内网直连访问仍按原有无账号模式工作。 |
| 请求体在 JSON / multipart 解析前缺少总量约束 | ASGI 边界限制声明长度及实际分块体积为 12 MB；工作区/Excel 原有 10 MB 业务限制保留。 |
| 自定义团队标签未 HTML 转义 | 生成器补齐渲染点，浏览器用例验证恶意标签仅显示文本。 |
| JSON 恢复未验证即修改内存 | 新增只读校验接口；校验日期、字段、依赖、模板环和保留对象键，失败保留内存及服务器内容。 |
| 审批状态与 API 健康颜色同名导致 500 | 响应用 approval_status 独立返回审批值；健康 status 保持兼容。 |
| 完成弹窗在日期校验前修改字段 | 改为通过校验再应用，失败点击也不会被自动保存带入数据库。 |
| 日期格式不同误报挪期、首次启动缺原始日期 | ISO 归一；初始化与恢复使用同一规则；清空重填仍保留原始日期，补齐六处浏览器回归。 |
| 旧阶段与当前已确认业务范围不一致 | 四阶段、20 项标准动作；旧阶段存入 retiredActions，自定义依赖重排有测试。提案中的 21 项系计数错误。 |
| 状态筛选与 Excel 扩展字段缺失 | 补齐四筛选及 Clear，导入/导出审批状态、双日期和完成日期，核验真实 XLSX 往返。 |
| SheetJS 0.18.5、Vitest 3.2.7 已知安全漏洞 | SheetJS 升至官方 0.20.3，Vitest 升至 4.1.11并更新锁文件；前后端依赖扫描通过。 |

SheetJS 的影响版本与修复版本以官方 [CVE-2024-22363](https://cdn.sheetjs.com/advisories/CVE-2024-22363) 和 [CVE-2023-30533](https://cdn.sheetjs.com/advisories/CVE-2023-30533) 为据；Vitest 以维护者的 [GHSA-82fw-gwwq-j7x9](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9) 为据。内置库来源为 `https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js`，保留原许可证。
